Use the `automdmctl` CLI to interact with AutoMDM, the lightweight telemetry platform for servers and workstations. Have a look at the [AutoMDM README](https://github.com/anilyagiz/automdm#readme) for more information.

## Installation

From the command line, install `automdmctl` with `npm install -g automdmctl`.

See the [documentation on enrolling hosts](https://automdm.com/guides/enroll-hosts#cli) for additional requirements for using `automdmctl package`.

## Usage

See the [automdmctl documentation](https://automdm.com/guides/automdmctl) or `automdmctl --help` for usage instructions.
