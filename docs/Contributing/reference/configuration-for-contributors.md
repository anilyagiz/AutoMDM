# Configuration for contributors

Don't use these AutoMDM server configuration options. For AutoMDM server configuration, please use the public [AutoMDM server configuration documentation](https://automdm.com/docs/configuration/automdm-server-configuration) instead. For YAML, please use the [public GitOps documentation](https://automdm.com/docs/configuration/yaml-files) instead.

These options in this document are only used when contributing to AutoMDM. They frequently change to reflect current functionality.

- [AutoMDM server configuration](#automdm-server-configuration)
- [YAML files](#yaml-files)

## AutoMDM server configuration

### s3_software_installers_disable_ssl

AWS S3 Disable SSL. Useful for local testing.

- Default value: false
- Environment variable: `AUTOMDM_S3_SOFTWARE_INSTALLERS_DISABLE_SSL`
- Config file format:
  ```yaml
  s3:
    software_installers_disable_ssl: false
  ```

### s3_carves_disable_ssl

- Default value: false
- Environment variable: `AUTOMDM_S3_CARVES_DISABLE_SSL`
- Config file format:
  ```yaml
  s3:
    carves_disable_ssl: false
  ```

### mdm.apple_apns_cert_bytes

The content of the Apple Push Notification service (APNs) certificate. An X.509 certificate, PEM-encoded. Typically generated via `automdmctl generate mdm-apple`.

- Default value: ""
- Environment variable: `AUTOMDM_MDM_APPLE_APNS_CERT_BYTES`
- Config file format:
  ```yaml
  mdm:
    apple_apns_cert_bytes: |
      -----BEGIN CERTIFICATE-----
      ... PEM-encoded content ...
      -----END CERTIFICATE-----
  ```

### mdm.apple_apns_key_bytes

The content of the PEM-encoded private key for the Apple Push Notification service (APNs). Typically generated via `automdmctl generate mdm-apple`.

- Default value: ""
- Environment variable: `AUTOMDM_MDM_APPLE_APNS_KEY_BYTES`
- Config file format:
  ```yaml
  mdm:
    apple_apns_key_bytes: |
      -----BEGIN RSA PRIVATE KEY-----
      ... PEM-encoded content ...
      -----END RSA PRIVATE KEY-----
  ```

### mdm.apple_scep_cert_bytes

The content of the Simple Certificate Enrollment Protocol (SCEP) certificate. An X.509 certificate, PEM-encoded. Typically generated via `automdmctl generate mdm-apple`.

- Default value: ""
- Environment variable: `AUTOMDM_MDM_APPLE_SCEP_CERT_BYTES`
- Config file format:
  ```yaml
  mdm:
    apple_scep_cert_bytes: |
      -----BEGIN CERTIFICATE-----
      ... PEM-encoded content ...
      -----END CERTIFICATE-----
  ```

The SCEP certificate/key pair generated by AutoMDM expires every 10 years. It's recommended to never change these unless they were compromised.

If your certificate/key pair was compromised and you change the pair, the disk encryption keys will no longer be viewable on all macOS hosts' **Host details** page until you turn disk encryption off and back on and the keys are [reset by the end user](https://automdm.com/docs/using-automdm/MDM-migration-guide#how-to-turn-on-disk-encryption).

### mdm.apple_scep_challenge

An alphanumeric secret for the Simple Certificate Enrollment Protocol (SCEP). Define a unique, static secret 32 characters in length and only include alphanumeric characters.

> SCEP is commonly applied to a number of certificate use cases. Notably, Mobile Device Management (MDM) systems like Microsoft Intune and Apple MDM use SCEP for PKI certificate enrollment.

- Default value: ""
- Environment variable: `AUTOMDM_MDM_APPLE_SCEP_CHALLENGE`
- Config file format:
  ```yaml
  mdm:
    apple_scep_challenge: scepchallenge
  ```

### license.enforce_host_limit

Whether AutoMDM should enforce the host limit of the license, if true, attempting to enroll new hosts when the limit is reached will fail.

- Default value: `false`
- Environment variable: `AUTOMDM_LICENSE_ENFORCE_HOST_LIMIT`
- Config file format:
  ```yaml
  license:
    enforce_host_limit: true
  ```

### license.enable_analytics

For approved AutoMDM Premium customers only.

Whether to send anonymous usage statistics. Overrides the value set by `enable_analytics` in the [Modify configuration](https://automdm.com/docs/rest-api/rest-api#modify-configuration) API endpoint.

- Default value: `true`
- Environment variable: `AUTOMDM_LICENSE_ENABLE_ANALYTICS`
- Config file format:
  ```yaml
  license:
    enable_analytics: false
  ```

### logging.tracing_enabled

Enables OpenTelemetry tracing and metrics export. When enabled, traces and metrics are sent to the OTLP endpoint configured via the standard `OTEL_EXPORTER_OTLP_ENDPOINT` environment variable.

- Default value: `false`
- Environment variable: `AUTOMDM_LOGGING_TRACING_ENABLED`
- Config file format:
  ```yaml
  logging:
    tracing_enabled: true
  ```

### logging.otel_logs_enabled

Enables exporting logs to an OpenTelemetry collector in addition to stderr output. When enabled, logs are sent to the OTLP endpoint configured via the standard `OTEL_EXPORTER_OTLP_ENDPOINT` environment variable. Logs are automatically correlated with traces via `trace_id` and `span_id` attributes.

> **Note:** All log levels, including debug, are always sent to the OpenTelemetry collector regardless of the `logging.debug` setting. The `logging.debug` flag only controls what appears in stderr output.

> **Note:** This option requires `logging.tracing_enabled` to be set to `true`. AutoMDM will fail to start if `otel_logs_enabled` is `true` but `tracing_enabled` is `false`.

- Default value: `false`
- Environment variable: `AUTOMDM_LOGGING_OTEL_LOGS_ENABLED`
- Config file format:
  ```yaml
  logging:
    tracing_enabled: true
    otel_logs_enabled: true
  ```

### mdm.apple_machineinfo_verify

Whether AutoMDM verifies the CMS/PKCS7 signature on Apple's `x-apple-aspen-deviceinfo` (MachineInfo) blob during MDM enrollment. When enabled (the default), enrollment requests whose MachineInfo signature does not verify against Apple's device-identity CA are rejected. Set to `false` to run verification in audit mode, where failures are logged but enrollment is allowed to proceed.

- Default value: true
- Environment variable: `AUTOMDM_MDM_APPLE_MACHINEINFO_VERIFY`
- Config file format:
  ```yaml
  mdm:
    apple_machineinfo_verify: false
  ```

### AUTOMDM_ENABLE_POST_CLIENT_DEBUG_ERRORS

Use this environment variable to allow `automdmd` to report errors to the server using the [endpoint to report an agent error](./API-for-contributors.md#report-an-agent-error). `automdmd` agents will always report vital errors to AutoMDM.

##### Example YAML

```yaml
license:
  key: foobar
  enforce_host_limit: false
```

## YAML files

### features.detail_query_overrides

This feature can be used to override "detail queries" hardcoded in AutoMDM.

> IMPORTANT: This feature should only be used when debugging issues with AutoMDM's hardcoded queries.
Use with caution as this may break AutoMDM ingestion of hosts data.

- Optional setting (dictionary of key-value strings)
- Default value: none (empty)
- Config file format:
  ```yaml
  features:
    detail_query_overrides:
      # null allows to disable the "users" query from running on hosts.
      users: null
      # this replaces the hardcoded "mdm" detail query.
      mdm: "SELECT enrolled, server_url, installed_from_dep, payload_identifier FROM mdm;"
  ```
